🔔 3. Backend Notification System (3-Tier Engine)

Designed to guarantee zero missed alerts across all device states. Each layer handles a distinct state where other layers cannot function.

Layer 1: In-App Banner App Active

Driven by Supabase Realtime WebSocket channel (garage:<id>). Renders an instant floating banner across whatever screen is active without disrupting input.

Layer 2: Unread Feed & Bell App Reopened

Durable records stored in public.garage_notifications created purely by PostgreSQL database triggers. Neither client nor owner can forge or delete them.

Layer 3: OS Tray Audio Push App Closed

Triggered by Database Webhooks calling the notify-garage Edge Function to dispatch Google FCM v1 high-priority tray notifications with custom chimes.

🧾 7. GST Engine & Invoice Templates

Automated Indian GST Rules Tax Compliance
  • Intra-State: Splits tax 50/50 into CGST + SGST (e.g. 18% = 9% CGST + 9% SGST).
  • Inter-State: Applies full tax slab as IGST (e.g. 18% IGST) based on customer state code.
  • Inclusive vs Exclusive Pricing: Toggleable per job card. Inclusive calculates backwards without shifting total.
  • HSN/SAC Code Rollups: Automatic grouping for GSTR-1 quarterly filing.
  • Auto Rounding: Exact rupee round-off printed on a dedicated line item.
6 Built-in PDF Invoice Themes Settings → Invoice Themes
  • Default (Original): Standard workshop letterhead with clean table structure.
  • Default (Two Logos): Dual branding for workshop + spare parts brand partner (Bosch, Castrol).
  • Luxury: Dark accent typography, fine border grids, executive aesthetic.
  • Advanced GST (Tally Style): Formal tax accountant format with complete HSN summary block.
  • Billbook: Classic two-column counter slip layout.
  • Simple: Minimalist single-sheet bill for routine services.

Q: Workshop not showing up in search?

Ensure GPS coordinates are set. Open the Admin Console → Settings → Workshop Details → Use Current Location → Save. A workshop without a latitude/longitude pin is excluded from customer radius searches.

Q: Background push alert didn't ring phone?

Check Android notification permissions. On Xiaomi, Vivo, or Oppo handsets, ensure the app is granted Autostart and Unrestricted Battery permissions in Android device settings.
